# 💼 Job Platform

A full-featured **Job Platform** web application built with **vanilla JavaScript**. It connects employers and job seekers in a single, easy-to-use interface.

Employers can create and manage job postings, while applicants can browse and apply to opportunities — all persisted locally in the browser.

## ✨ Features

- 👔 **Employer mode** — post jobs with title, company, location, type & salary
- 🔎 **Candidate mode** — search and filter jobs by keyword and job type
- ✅ **One-click apply** with applied-state tracking
- 🗑️ **Manage postings** — delete jobs you no longer need
- 💾 **Local persistence** — data saved via `localStorage` (no backend required)
- 📱 **Responsive UI** — works on desktop and mobile

## 🧱 Tech Stack

| Layer     | Technology            |
|-----------|-----------------------|
| Structure | HTML5                 |
| Styling   | CSS3 (custom props)   |
| Logic     | Vanilla JavaScript    |
| Storage   | Browser localStorage  |

## 🚀 Getting Started

1. Clone or download this repository.
2. Open `index.html` in any modern browser.
3. That's it — sample jobs are seeded automatically on first run.

```bash
# optional: serve locally
npx serve .
```
